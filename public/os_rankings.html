The Best Operating Systems (According To Your Boy)

My top 3 operating systems of all time

1: Windows 11

Windows 11 has been my main OS for the past couple of years. I grew up with Windows 10, and hesitated to upgrade for about 2 or 3 years. And honestly, Windows 10 is still the OG

For Christmas in 2023, I finally made the jump. I got a laptop with Windows 11 pre installed, and since then it's been my main os. After a while, my parents' computer got the forced upgrade to Windows 11, so now the only laptop in the house still running Windows 10 is the gaming laptop I havn't used in months.

What I'm really trying to say is even though I had more time and experience with Windows 10, waiting to upgrade was a solid choice concidering Windows 11 having various issues when it was first released, so when I finally did upgrade, I was met with a great looking, patched, beautiful install of the new operating system from Microsoft

2: Android

Stepping away from desktop operating systems for a second, Android is definetly my second favorite OS of all time. I have only used Android phones, because they are simply the best. The reason it is not my first favorite is because while I probably use my phone way more than my computer, my laptop does way more than my phone can do, and so therefore Windows takes the W.

3: Windows 10

As I said before, I grew up with Windows 10, especially in school. I remember the older build of Windows 10, with the hero wallpaper, which I didn't really like, because it felt like I was trapped in a little room with a big window that was too small to escape lol.

Anyway, even though Windows 10 is going to be discontinued within the next 2 months :(, and it will definely be very sad when it is, even though I never touch it anymore, I will always have fond memories of it. It was nice knowing you, Windows 10.

Again the reason this is my second favorite non-mobile OS is because I had more time with it, and I got to know it better. It's like when your friends change over the years, you get to know them better, and you can appreciate them more, but you sometimes think about the old times and the awesome memories you had when life was simpler. I will definely miss Windows 10 being a thing. When I have kids, I will tell them about Windows 10, just like my parents tell me about the good old days with Windows 95 and floppy disks.

4: Debian Linux

This is where we get into the reasons why you would use a certain OS. Windows is for school, work, gaming, and everything you use, well, windows for. Linux is for weirdos like me who like to set up webservers that redirect every request to a rickroll, or try and make their own ui, or whatever they put their hearts to.

The reason I said Debian in specific is because it is really the only distro I have put on my systems on purpose. When I say debian, I mean anything based on Debian, because the commands are the same, sure they might have different uis, but the core is the same, especially the package manager, apt, and since I mostly use the terminal.

I first got introduced to Linux via Raspberry Pi OS, when I got my first raspberry pi, a 3b. I have a custom firmware on my 3D printer that runs on a very basic linux shell, but other than that, I really only use Debian based operating systems. I really have never used any other distro; I tried arch in a vm once, and never touched it again.
